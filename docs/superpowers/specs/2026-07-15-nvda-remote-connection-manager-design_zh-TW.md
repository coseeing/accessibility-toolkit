# NVDA Remote 連線管理器設計

## 目標

將 Remote PlusPlus 風格的連線管理功能加入獨立版 NVDA Remote 用戶端。使用者
可以儲存 Relay 連線資訊、整理連線，並在不需要 NVDA 執行環境的情況下快速連線。

## 範圍

本功能包含儲存連線、群組、搜尋、排序、連線連結、可設定的快速連線預設項目，以及
wxPython 連線管理器。

明確排除所有 NVDA 專用概念：

- 控制端／被控制端連線模式，以及反轉模式連線；
- 本機／自架控制伺服器連線；
- 應用程式啟動時自動連線。

所有儲存的項目都代表一般的對外 Relay 連線。

## 架構

建立獨立於 wxPython 與傳輸實作的應用程式層級連線管理模組。此模組包含經過驗證的
已儲存連線模型、以 JSON 為基礎的儲存庫，以及提供連線與管理操作的服務。wxPython
檢視介面使用此服務，不直接存取 JSON。

`NvdaRemoteAppService` 接收連線管理服務，並提供連線至已儲存項目或已設定快速連線
預設項目的操作。若目前已有其他連線，連線至已儲存項目時會先執行正常的中斷連線
流程，再啟動所選的 Relay 連線。

管理器的設定會與語音偏好設定分開，並使用應用程式既有的執行階段設定位置：開發環境
位於工作目錄，封裝版本則位於執行檔目錄。寫入時先建立同層的暫存檔，再使用
`os.replace` 取代目標檔案，避免寫入失敗造成現有設定損毀。檔名為
`nvda_remote_connections.json`。

## 資料模型與持久化

JSON 文件包含以下欄位：

- `format_version`：整數 `1`；
- `active_group`：上次選取的群組；
- `close_on_connect`：開始連線且未立即發生錯誤時，是否關閉連線管理對話框；
- `quick_connect_id`：主視窗快速連線動作用的已儲存連線 ID；沒有預設項目時為
  `null`；
- `groups`：由群組名稱對應至有順序之已儲存連線的映射。

每筆已儲存連線包含 UUID `id`、不可為空的顯示名稱 `name`、不可為空的主機 `host`、
介於 1 到 65535 的整數連接埠 `port`、不可為空的金鑰 `key`，以及表示是否略過 TLS
憑證驗證的布林值 `insecure`。所有群組中的連線 ID 必須全域唯一；包含重複 ID 的
設定檔視為無效。

初始文件包含不可刪除的 `Default` 群組、空的連線清單，且沒有快速連線預設項目。刪除
非預設群組時，該群組的所有連線都會移至 `Default`。刪除快速連線預設項目時，會將
`quick_connect_id` 清除為 `null`。

連線金鑰會以明文儲存在本機執行階段設定檔中，與 Remote PlusPlus 的行為一致。設定檔
屬於執行階段資料，不是儲存庫的檔案。

如果檔案無法剖析或未通過驗證，應用程式會記錄錯誤，保留原始檔案，並繼續使用記憶體中
空白的預設文件。載入時不得覆寫無法讀取的檔案。

## 管理操作

管理器支援建立、重新命名與刪除群組、列出群組、記住目前群組，以及在刪除群組時將其
項目移至 `Default`。`Default` 不可重新命名或刪除。群組名稱會去除前後空白、不得為空，
並以區分大小寫的方式判斷是否重複。群組管理器支援在一次確認操作中刪除多個非預設群組。

連線支援在群組內新增、讀取、更新、刪除，以及相鄰排序，並可在一次確認操作中刪除多個
已選取項目。搜尋會在選定群組中依不分大小寫的名稱或主機進行篩選。在篩選後的清單中
重新排序時，會交換底層相鄰的可見項目，以保留 Remote PlusPlus 的行為。

使用者可以將任一已儲存連線指定為快速連線預設項目，其 ID 會持久化儲存。沒有預設項目，
或預設項目已被刪除時，快速連線功能不可用。

管理器使用既有的 NVDA Remote URL 格式複製連線連結：
`nvdaremote://host[:port]?key=<經 URL 編碼的金鑰>&mode=slave`。只有停用憑證驗證時
才會附加 `&insecure=true`。IPv6 主機使用方括號，預設連接埠 6837 則省略。
`mode=slave` 是提供給連結接收端的固定相容性資訊；本用戶端不儲存也不允許編輯連線
模式。此格式由本專案的格式化函式產生並測試，不依賴 NVDA 專用的
`ConnectionInfo.getURLToConnect()` API。

## 使用者介面

主視窗不提供手動輸入主機、連接埠或金鑰的欄位。所有連線目標都必須先在連線管理器中
建立，使用者再從已儲存清單或已設定的快速連線項目進行連線。主視窗新增：

- **管理連線**：開啟連線管理器對話框；
- **快速連線**：連線至已設定的預設項目。

當 `quick_connect_id` 為 `null`、指向不存在的項目，或目前正在連線或已連線時，快速
連線會停用。管理連線入口只在連線嘗試進行期間停用，已連線時仍可使用，讓使用者能選取
其他已儲存項目；此時會先執行正常的中斷連線流程，再連線至新目標。主視窗也保留獨立的
中斷連線操作，閒置時停用。刪除預設項目後，主視窗會立即更新並停用快速連線。

管理器對話框提供群組選取、群組管理、搜尋，以及顯示名稱、主機與連接埠的連線清單。它
提供新增、編輯、刪除與關閉操作。雙擊項目即可連線。對話框也提供右鍵選單與鍵盤操作，
可用於編輯、刪除、複製連線連結、設為快速連線，以及上移／下移項目。它包含持久化儲存
的**連線後關閉**選項。啟用時，在連線嘗試開始且未立即發生錯誤後，只會關閉管理器
對話框，不會關閉主應用程式視窗。

連線編輯器會在儲存前驗證必要欄位。無效的主機／名稱／金鑰值，以及超出 1–65535 範圍
的連接埠，會顯示可存取的 wx 錯誤對話框，且不會變更已儲存資料。名稱、主機與金鑰會
去除前後空白，且處理後不得為空；主機與連接埠使用不同欄位。編輯器提供「產生金鑰」
操作，使用密碼學安全的產生器建立七位數十進位金鑰。連線失敗使用應用程式既有的錯誤
回報機制；TLS 憑證錯誤只能依據該連線明確設定的 `insecure` 值重試。

連線清單的鍵盤操作沿用 Remote PlusPlus 中適用的快速鍵：`Alt+Up` 與 `Alt+Down` 排序、
`F2` 編輯、`Delete` 刪除、`Ctrl+A` 全選，以及在只選取一個項目時以 `Ctrl+C` 複製
連線連結。按一般 Enter 或啟用清單項目即可連線；不包含反轉模式的 `Shift+Enter`。

## 測試

單元測試涵蓋儲存庫預設值、驗證、CRUD、群組移動、搜尋、排序、快速連線指定與清除、
原子儲存，以及損毀檔案復原。服務測試涵蓋連線至已儲存項目、快速連線、失效的預設項目，
以及取代現有連線。wx 測試涵蓋管理器操作，以及已儲存／預設／連線狀態變更時快速連線
與管理連線控制項的啟用狀態。

當聚焦測試與儲存庫完整測試 `pytest tests/unit tests/integration -v` 全部通過時，即表示
實作完成。
