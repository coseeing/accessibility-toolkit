從收到遠端語音資料到播放出聲音，主要會經過這些 class:

1. RelayTransport
2. ClientController
3. MessageRouter
4. SpeechSequence
5. OutputManager
6. NvdaControllerSpeechOutput 或 Pyttsx3SpeechOutput

實際資料流如下:

應用啟動時，main() 先建立 speech backend，預設是 nvda_controller，也可以切到 pyttsx3，然後把目前選到的 speech_output 注入 ClientController。
參考:
- src/ui/main.py:47
- src/ui/main.py:80

ClientController 初始化時做兩件關鍵事:
- 把 OutputManager 建起來
- 把 transport.set_message_handler(self._handle_transport_message) 綁上去，讓網路收到的訊息都先進 controller
參考:
- src/application/controller.py:40
- src/application/controller.py:48
- src/application/controller.py:58

遠端送來語音資料後，RelayTransport.receive_once() 先從 socket 收 frame，接著交給 JSONSerializer.deserialize() 解析 JSON。
參考:
- src/remote_core/transport/relay.py:76
- src/remote_core/transport/relay.py:89
- src/remote_core/serializer.py:34

如果 payload 的 type == "speak"，JSONSerializer 會先把 sequence 裡的資料恢復成可用的 speech items；字串保留原樣，像 BreakCommand、PitchCommand、RateCommand 這類命令會被還原回對應物件。
參考:
- src/remote_core/serializer.py:12
- src/remote_core/models/speech_sequence.py:13

接著 ClientController._handle_transport_message() 會把 payload 丟給 MessageRouter.handle_message()。如果訊息型別是 speak，router 會呼叫 SpeechSequence.from_remote_payload(payload)，再把結果交給 OutputManager.handle_speech()。
參考:
- src/application/controller.py:181
- src/remote_core/routing/message_router.py:23
- src/remote_core/routing/message_router.py:25
- src/remote_core/models/speech_sequence.py:46
- src/application/services.py:30

OutputManager 本身不處理語音內容，它只做轉發:
- speech_output.speak(speech)
參考:
- src/application/services.py:30

最後就看目前選的是哪個 backend。

如果是 NvdaControllerSpeechOutput:
它把 SpeechSequence 轉成 SSML，然後呼叫 DLL 的 nvdaController_speakSsml(...) 真正發聲。
參考:
- src/adapters/windows/nvda_controller.py:68

如果是 Pyttsx3SpeechOutput:
它逐項遍歷 SpeechSequence.items，文字會排進 task queue，最後在 _speak_text() 裡呼叫 engine.say(text) 和 engine.runAndWait() 發聲。
參考:
- src/adapters/outputs/drivers/pyttsx3.py:55
- src/adapters/outputs/drivers/pyttsx3.py:134

可濃縮成一條 call chain:

RelayTransport.receive_once()
-> JSONSerializer.deserialize()
-> ClientController._handle_transport_message()
-> MessageRouter.handle_message()
-> SpeechSequence.from_remote_payload()
-> OutputManager.handle_speech()
-> speech_output.speak()
-> NvdaControllerSpeechOutput.speak() / Pyttsx3SpeechOutput.speak()
-> 實際 TTS backend 發聲
